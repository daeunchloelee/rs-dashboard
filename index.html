최근 주요 공시 하이라이트

시가총액 상위 및 이슈성 종목 11곳의 최근 DART 공시 (수동 갱신 스냅샷)

데이터 출처 & 갱신 방식

  • 종목 목록·상장일·공모가·시초가 수익률: 유진투자증권·삼성증권 IPO 리포트, DART, 언론 보도를 교차 확인해 수집한 고정 데이터입니다 (data/companies.json).
  • 현재가·최근 수익률: GitHub Actions가 평일 장 마감 후 하루 한 번 네이버 증권의 공개 시세 API를 호출해 그날의 종가로 data/prices.json 을 갱신하고, 이 페이지가 그 값을 그대로 불러와 보여줍니다. 분·시간 단위의 장중 시세는 추적하지 않습니다.
  • 네이버 API에서 조회하지 못한 종목(신규 영숫자 코드, 코드 미확인 등)은 리포트 발행 시점의 스냅샷 수익률로 표시되며, 표에 "스냅샷" 배지로 구분됩니다.
  • 가이던스 vs 실적: 표에서 종목을 클릭하면 나오는 패널에서 볼 수 있습니다. 가이던스(추정치)는 자동으로 가져올 방법이 없어 — 증권신고서 "인수인의 의견" 원문을 DART가 API로 제공하지 않습니다 — 직접 입력해야 하며, 입력한 내용은 이 브라우저(localStorage)에만 저장됩니다(다른 기기·브라우저에는 보이지 않음). 실제 실적은 data/actuals.json에 저장되며, GitHub Actions의 "실제 실적 자동 갱신" 워크플로를 수동으로 실행하면 DART Open API에서 자동으로 채워집니다 — 전년도까지는 사업보고서(연간) 기준, 올해는 공시된 가장 최근 분기·반기보고서(누적) 기준이며 패널에 시점이 표시됩니다.

읽을 때 참고할 점

  • 이 시세는 네이버 증권의 비공식(미문서화) API를 사용합니다 — 형식이 바뀌거나 일시적으로 막히면 자동으로 스냅샷 값으로 대체됩니다.
  • 하루 한 번, 장 마감 후 종가 기준으로만 갱신됩니다. 장중에는 전날 종가가 그대로 표시되며, 주말·공휴일에는 직전 거래일 종가가 유지됩니다.
  • 스팩(SPAC)·리츠 종목은 공모가 개념이 다르거나 없어 수익률 계산에서 제외될 수 있습니다. 코넥스 상장 종목은 집계에서 제외했습니다.
  • 가이던스 입력값은 브라우저 저장공간을 지우면 함께 사라집니다 — 입력 패널의 "JSON 내보내기"로 백업하거나 Claude에게 전달해 파일에 영구 반영할 수 있습니다.
  • 투자 판단을 위한 조언이 아니며, 매매 전 최신 공시와 시세를 반드시 증권사 앱 등에서 다시 확인하시기 바랍니다.
